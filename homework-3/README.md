## Чеклист
### Обязательные
- Навигация (2 экрана с аргументами)
- Архитектура (MVVM с Repository)
- Coroutines + Retrofit
- UI состояния (Loading, Error, Empty, Success)
- Избранное (локальное хранение)
- Compose + Material3
- Navigation Compose
- ViewModel + viewModelScope
